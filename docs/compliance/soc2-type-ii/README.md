# SOC 2 Type II Assessment Pack

This pack provides a practical readiness and assessment structure for a SOC 2 Type II examination over a service organisation. It is intended for a banking institution or banking technology provider whose customers rely on controls over security, availability, processing integrity, confidentiality, or privacy.

## Contents

1. [`knowledge-base.md`](knowledge-base.md) — Trust Services Criteria, scope, control design, evidence, and Type II period concepts.
2. [`assessment-method.md`](assessment-method.md) — readiness, examination planning, sampling, exceptions, complementary controls, and reporting.
3. [`assessment-workbook.md`](assessment-workbook.md) — control-family testing procedures and evidence requests.
4. [`evidence-register.md`](evidence-register.md) — system description inputs, evidence index, samples, exceptions, and management responses.

## Important boundary

This is a readiness and internal assessment aid, not an AICPA SOC 2 report or an auditor opinion. A SOC 2 examination must be performed and reported by an independent licensed CPA firm under applicable professional standards, using the applicable AICPA Trust Services Criteria (TSC), description criteria, and engagement requirements. Confirm the chosen categories and period with the service auditor.

## Recommended sequence

1. Define the system, services, boundaries, commitments, and selected TSC categories.
2. Write a truthful system description before collecting evidence.
3. Map commitments and risks to controls and responsible personnel.
4. Operate controls consistently throughout the Type II period and retain evidence as work occurs.
5. Test populations, investigate exceptions, and assess deviations for frequency and impact.
6. Prepare management responses, corrective action, and customer-facing communication.
