# Certification Exam Preparation

This area contains structured learning, assessment, and exam-preparation material for professional certifications. Each certification should have its own folder and should keep learning content separate from regulatory and framework compliance packs.

## Certification tracks

- [`isaca-aair/`](isaca-aair/) — ISACA Advanced in AI Risk (AAIR)

## Standard certification-folder structure

Each certification track should include:

1. `README.md` — certification scope, official-source links, eligibility boundary, and pack map.
2. `knowledge-base.md` — concepts and domain notes.
3. `learning-path.md` — staged study plan and practical deliverables.
4. `assessment-method.md` — learning checks and applied assessment method.
5. `assessment-workbook.md` — practice worksheets.
6. `evidence-register.md` — study evidence, control tests, findings, and error log.
7. `exam-preparation.md` — study strategy, question technique, and readiness gate.
8. `mock-exam.md` — original practice assessment with answer key and rationales.

Only original practice content belongs here. Official exam questions, answer explanations, candidate-only material, or other copyrighted content must not be copied into the repository.
