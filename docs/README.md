# Learning Documentation

This directory separates the programme into the core leadership curriculum and compliance assessment packs.

## Directory structure

### [`learning-path/`](learning-path/)

The scenario-led Information Security GRC leadership curriculum:

- [`01-preparation.md`](learning-path/01-preparation.md) — role interpretation and baseline assessment
- [`02-learning-path.md`](learning-path/02-learning-path.md) — six-stage development path
- [`03-scenarios.md`](learning-path/03-scenarios.md) — scenario-based practice
- [`templates.md`](learning-path/templates.md) — working templates

### [`compliance/`](compliance/)

Framework-specific knowledge bases and assessment packs:

- [`pci-dss-4.0.1/`](compliance/pci-dss-4.0.1/) — PCI DSS v4.0.1 banking assessment
- [`sox/`](compliance/sox/) — SOX ITGC compliance
- [`soc2-type-ii/`](compliance/soc2-type-ii/) — SOC 2 Type II assessment
- [`change-management-audit/`](compliance/change-management-audit/) — audit change logs and detect unapproved changes

### [`certification-exam-prep/`](certification-exam-prep/)

Certification-specific learning and exam preparation:

- [`isaca-aair/`](certification-exam-prep/isaca-aair/) — ISACA Advanced in AI Risk learning and exam preparation

Each compliance pack follows the same structure:

1. `README.md` — scope, use, and implementation sequence
2. `knowledge-base.md` — framework concepts and control knowledge
3. `assessment-method.md` — assessment lifecycle and testing approach
4. `assessment-workbook.md` — procedures, evidence requests, and conclusion worksheet
5. `evidence-register.md` — evidence, sampling, issue, and remediation registers
